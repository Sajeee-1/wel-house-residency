    How the calculation works
    • Own units = current − previous. Meters are 4-digit (0–9999); if current < previous the meter rolled over: (10000 − previous) + current. E.g. 9999 → 100 = 101 units.
    • Common units = bill units − all house units, split equally. If house meters exceed the bill, the difference is taken off equally (and flagged).
    • Rate = (bill amount − fixed charge) ÷ bill units. Amount = fixed ÷ houses + billable units × rate, rounded so the total equals the bill exactly.
